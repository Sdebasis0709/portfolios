# Debasis Sahoo | Portfolio

Multi-page spatial UI portfolio built with HTML, CSS and JavaScript (Three.js for the 3D scenes).

Pages: `index.html` (Home), `experience.html`, `skills.html`, `contact.html`

Each page is self-contained (CSS and JS are inside the file). Three.js and the Sora font load from a CDN, so an internet connection is needed.
